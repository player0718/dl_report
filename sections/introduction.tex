\section{Introduction}
\label{sec:intro}

\paragraph{Motivation.}
Vision Transformers (ViTs) have shown strong performance in image
classification, but they usually depend more on data and training recipe
than convolutional networks \citep{dosovitskiy2021vit,touvron2021deit}.
This is especially important on smaller datasets, where a model may fit
the training set well but still generalize poorly. In such settings,
regularization is not only a small improvement trick, but an important
part of the training pipeline. Understanding which regularization
methods help most in this regime is therefore useful for both practice
and analysis.

\paragraph{Why CIFAR-100 with ViT-Tiny.}
We study CIFAR-100 with ViT-Tiny/16 as a modest-data, modest-model
setting. CIFAR-100 is much smaller than ImageNet, but it still contains
100 classes and is not a trivial classification task
\citep{krizhevsky2009cifar}. At the same time, ViT-Tiny is small enough
to train efficiently, while still being sensitive to training choices
during fine-tuning. This makes the setting suitable for controlled
comparison: the baseline is strong enough to be meaningful, but there is
still room to observe differences between regularization methods.

\paragraph{Contributions.}
This paper makes the following contributions:
\begin{itemize}
  \item We establish a unified fine-tuning baseline for ViT-Tiny/16 on
        CIFAR-100 and use it as the common reference point for all
        later comparisons.
  \item We compare several regularization families under the same
        training protocol, including weight decay, dropout-based
        methods, data augmentation, and label smoothing with early
        stopping.
  \item We additionally study layer-wise learning rate decay (LLRD) with
        staged fine-tuning as an optimization strategy for pretrained
        ViT adaptation.
  \item We provide a cross-method comparison and discuss which methods
        are most effective for improving generalization in this setting.
\end{itemize}
