\section{Experiments}
\label{sec:experiments}

This section describes the shared experimental setting used in all
comparisons. We keep the dataset, model, training budget, and evaluation
protocol fixed, and only change the target regularization method in each
experiment.

\subsection{Dataset}
\label{sec:exp:data}
We use CIFAR-100 \citep{krizhevsky2009cifar}, which contains 50,000
training images and 10,000 test images from 100 classes. We reserve
10\% of the training set for validation, resulting in 45,000 training
images and 5,000 validation images. The official test set is used only
for final evaluation. The same split with seed 42 is used in all runs.

\subsection{Model}
\label{sec:exp:model}
We fine-tune \texttt{vit\_tiny\_patch16\_224} from \texttt{timm}
\citep{wightman2019timm}, using ImageNet-pretrained weights
\citep{dosovitskiy2021vit}. CIFAR-100 images are resized to
$224 \times 224$ to match the model input size. The original
classification head is replaced with a 100-class linear layer, while
the remaining parameters are initialized from the pretrained checkpoint.

\subsection{Training Protocol}
\label{sec:exp:training}
Unless otherwise noted, all experiments use AdamW
\citep{loshchilov2019adamw} with base learning rate $3\times10^{-4}$,
a 3-epoch linear warmup, and cosine decay
\citep{loshchilov2017sgdr}. We use batch size 64, mixed precision
training, and gradient clipping with $\lVert g\rVert_2 = 1.0$. To keep
the comparison controlled, only the target regularization-related
setting is changed across experiments. Unless otherwise stated, all additional regularization-related parameters in the baseline are set to 0 or left at their default values.

\subsection{Evaluation Metrics}
\label{sec:exp:eval}
For each run, we record training loss, training accuracy, validation
loss, and validation accuracy at every epoch. We select the checkpoint
with the highest validation accuracy and report its validation accuracy,
test accuracy, and train--validation gap. Training time is also
reported for efficiency comparison. Unless otherwise stated, the current
results are based on single-seed runs.
