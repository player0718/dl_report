\section{Methodology}
\label{sec:methodology}

This report compares a clean ViT-Tiny/16 fine-tuning baseline with five
simple regularization or optimization strategies on CIFAR-100. The purpose
of this section is only to define what each method changes at a high level;
the exact hyperparameters, training budget, and evaluation protocol are
reported in \cref{sec:experiments}.

The baseline uses the pretrained ViT-Tiny/16 model without additional
regularization beyond standard resizing and normalization.
\label{sec:method:baseline}
All later experiments modify one part of this baseline at a time so that the
effect of each method can be compared under the same general setting.

\textbf{Weight decay} adds an $L_2$-style penalty through AdamW to discourage
large parameter values during fine-tuning.
\label{sec:method:wd}
In our experiments, this method tests whether constraining the weights helps
the pretrained model generalize better on CIFAR-100.

\textbf{Dropout} randomly remove information during training,
either from hidden activations, attention weights, residual paths, or input
patches.
\label{sec:method:dropout}
We also include R-Drop \citep{wu2021r}, which encourages two stochastic
forward passes of the same input to produce similar predictions. These methods
all aim to reduce overfitting by making the model less dependent on any single
feature, token, or path.

\textbf{Data augmentation} regularizes the model by increasing the diversity of
the training images.
\label{sec:method:aug}
We consider standard image-level transformations such as RandAugment
\citep{cubuk2020randaugment} and Random Erasing \citep{zhong2020random}, as
well as sample-mixing methods such as Mixup \citep{zhang2018mixup} and CutMix
\citep{yun2019cutmix}. These methods change the input distribution while
leaving the model architecture unchanged. Since sample-mixing techniques produce interpolated or regional mixed inputs, the corresponding ground-truth labels are no longer one-hot but converted into soft targets. Consequently, we employ a soft-target cross-entropy loss during training.

\textbf{Label smoothing and early stopping} regularize different parts of the
training process.
\label{sec:method:lsearly}
Label smoothing softens the target labels so that the classifier is not trained
to be overly confident, while early stopping selects the checkpoint before the
model overfits the training set.

\textbf{Layer-wise learning rate decay} changes the optimization schedule for
the pretrained backbone.
\label{sec:method:llrd}
Lower ViT layers are updated more conservatively than higher layers and the
classification head, reflecting the intuition that early visual features are
more transferable while later layers need more task-specific adaptation
\citep{dong2022exploring,liu2022convnext}.
