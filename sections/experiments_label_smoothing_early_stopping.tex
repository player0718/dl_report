\paragraph{Results.}
With label smoothing set to $\epsilon = 0.1$ and early-stopping patience set to 25 epochs, the combined run achieves a best validation accuracy of 83.86\% at epoch 92. The corresponding test accuracy is 83.58\%, with a test loss of 1.3598. At the best-validation epoch, the training accuracy is 93.12\%, giving a train--validation gap of 9.26 percentage points. This is higher than the 100-epoch clean baseline, which reaches 80.42\% best validation accuracy and 79.65\% test accuracy.

\paragraph{Discussion.}
Label smoothing modifies the training target by discouraging over-confident predictions. This is relevant for CIFAR-100 because the dataset contains 100 fine-grained classes, and some categories are visually similar. Early stopping mainly acts as a validation-based checkpoint selection mechanism in this run: the best checkpoint occurs at epoch 92, so the patience setting does not substantially reduce training cost. Overall, the result shows a measurable improvement over the clean baseline, but it should be interpreted as evidence for this particular setting rather than as a full hyperparameter study.
